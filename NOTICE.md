# Source and integration notice

The visual hierarchy was recreated from the user-provided CoinFactory screenshots and saved HTML as a reference. No CoinFactory backend is used.

The Pons V2 integration was derived from the user-provided `ponscharity-main` source and checked against current public Pons V2 integration documentation. All charity-specific routing was intentionally excluded. The direct integration writes the creator's selected fee-recipient address into Pons V2 launch parameters.

This project does not include or claim ownership of CoinFactory, Robinhood, or Pons branding. The included "RHC Factory" mark is original and generic.
